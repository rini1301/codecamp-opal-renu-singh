3. `03-interactive-output-card.png` - captured; shows the generated Mistral AI dashboard and PASS badge. Claim sources appear as generic labels/IDs, not clickable URLs.
4. `04-google-sheet-log.png` - captured; shows populated claim rows. Visible columns omit source URLs and a repeated header appears mid-sheet.
